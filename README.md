# ✦ WELCOME TO MUVNA ✦

### A NEW WAY TO EXPERIENCE MOVIES

*More than a movie website. A cinematic journey.*

</div>

---

<img src="https://capsule-render.vercel.app/api?type=rounded&height=85&color=0:101B3B,100:273F7B&text=01%20%E2%80%94%20ABOUT%20THE%20PROJECT&fontColor=FFFFFF&fontSize=24&animation=fadeIn" width="100%"/>

<br/>

**MUVNA** is a modern movie discovery website created for cinema lovers who want to explore movies through an elegant, interactive, and immersive experience.

Designed with a cinematic dark interface, vibrant gradients, and smooth interactions, MUVNA makes discovering movies enjoyable and effortless.

From trending titles to top-rated movies, every section is designed to help users find their next favorite story.
